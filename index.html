Project Details:

These were the first programming projects that I was tasked with completing in SETU. We had to design and write a program that covered as many Processing functions as possible, both ones we had learned in class and ones that were not covered. It also needed to have a conditional if-else statement and the standard code commenting and indenting.

For the first assignment, I wanted to recreate the effect you get from winning at solitaire where all the cards will draw themselves bouncing off the screen and the effect is pretty neat. The project works by clicking on the screen to spawn a card that bounces using some example code of a ball bouncing that I adapted to work with my project. You can drag the card around before releasing it also, I think I would have liked it if the card shown could have been random from all the cards in the deck but I was satisfied with the end result.

For the second assignment, I went a bit more simple as the last project was "very advanced" for a beginner project and so I just did a very simple advent calendar. I used different built-in functions for this like the time and date functions because I wanted an excuse to use them.
This project works by checking the systems date for the 1st to the 25th of December. It would then tell you what day of advent it is and give you a present based on a set list. It would then show an image of a house with falling snow and a song would start playing. If it was outside Christmas, it wouldn't let you into the program. I was happy with this in the end but I had a lot more initial ideas about how you would get to click on a date on the calendar and get your present that way and I also wanted the snow to be intractable in some way. But I was under time pressure to get the project done and I also lacked experience in how to implement it properly.
